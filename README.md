# ShoeMart - Shoe Purchasing Web App

A modern, fully functional shoe e-commerce web application built with HTML, CSS, and JavaScript.

## Features

### 🛍️ Product Catalog
- **Extensive Shoe Collection**: 12+ shoes across multiple categories
- **Categories**: Men's, Women's, and Kids' shoes
- **Product Details**: Name, price, ratings, reviews, and descriptions
- **Filtering**: Easy-to-use category filters to browse shoes by type

### 🛒 Shopping Cart
- **Add to Cart**: Select size and quantity before adding
- **Cart Management**: Update quantities or remove items
- **Persistent Storage**: Cart items saved in browser's local storage
- **Real-time Updates**: Cart count badge updates instantly

### 💳 Checkout System
- **Product Details Modal**: View full product information before purchase
- **Size Selection**: Multiple size options for each shoe
- **Order Form**: Complete checkout with shipping and billing information
- **Order Summary**: View subtotal, shipping, and total before confirming

### 🎨 User Interface
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **Modern Styling**: Clean, professional design with smooth animations
- **Interactive Elements**: Hover effects, modals, and smooth transitions
- **Accessibility**: Font Awesome icons and clear navigation

### ⭐ Product Features
- **Star Ratings**: Visual star ratings with review counts
- **Product Categories**: Organized by Men, Women, and Kids
- **Price Display**: Clear pricing for all products
- **Product Descriptions**: Detailed information about each shoe

## How to Use

1. **Clone or Download** the project files
2. **Open** `index.html` in your web browser
3. **Browse** the shoe collection using category filters
4. **Click** "View Details" on any shoe to see full information
5. **Select** size and quantity, then click "Add to Cart"
6. **Click** the shopping cart icon to view your cart
7. **Proceed to Checkout** to complete your purchase
8. **Fill in** your information and submit to place the order

## Key Functionality

### Product Display
- Products are dynamically rendered from a JavaScript array

### Shopping Cart

### Responsive Design
- Mobile-first approach
- Adapts to different screen sizes
- Touch-friendly buttons and controls
- Optimized navigation for all devices
